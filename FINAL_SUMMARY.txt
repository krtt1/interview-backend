================================================================================
                         TROUBLESHOOTING
================================================================================

Backend won't start?
  → Check MySQL is running on port 3307
  → Verify .env has correct database URL
  → Run: npm install
  → See: TROUBLESHOOTING_GUIDE.md

Dropdowns empty?
  → Run: npm run seed:mock
  → Verify data in database
  → Check API response in browser
  → See: TROUBLESHOOTING_GUIDE.md

CORS error?
  → Verify frontend port in .env ALLOWED_ORIGINS
  → Restart backend: npm run dev
  → Clear browser cache
  → See: TROUBLESHOOTING_GUIDE.md

Database error?
  → Run: npm run reset:db
  → Verify MySQL is running
  → Check port 3307 is accessible
  → See: TROUBLESHOOTING_GUIDE.md
