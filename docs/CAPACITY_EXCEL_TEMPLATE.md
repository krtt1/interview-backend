## 📊 คำอธิบายแต่ละคอลัมน์

### คอลัมน์ A: รหัสพนักงาน (Required)
- **ประเภท:** Text
- **รูปแบบ:** ตัวเลข 13 หลัก
- **ตัวอย่าง:** 1234567890123
- **หมายเหตุ:** ต้องมีอยู่ในระบบ (tb_employee) ก่อน

### คอลัมน์ B-G: ข้อมูลพื้นฐาน
- **B - คำนำหน้า:** นาย, นาง, นางสาว
- **C - ชื่อ-นามสกุล:** ชื่อเต็ม
- **D - แผนก:** ชื่อแผนก/กลุ่มงาน
- **E - อายุ:** ตัวเลข
- **F - ระดับการศึกษา:** ปริญญาตรี, ปริญญาโท, ปริญญาเอก
- **G - ระยะเวลาปฏิบัติงาน:** เช่น "5 ปี", "2 ปี 6 เดือน"

### คอลัมน์ H-O: ทักษะพื้นฐาน
**ค่าที่ใช้ได้:**
- พื้นฐาน
- ปานกลาง
- ดี
- ดีมาก
- เชี่ยวชาญ

**คอลัมน์:**
- **H:** การเขียนหนังสือราชการ
- **I:** การสรุปการประชุม
- **J:** การใช้คอมพิวเตอร์
- **K:** การสื่อสาร
- **L:** หลักระบาดวิทยา
- **M:** Excel
- **N:** PowerPoint
- **O:** AI Tools

### คอลัมน์ P-R: ภาษาอังกฤษ
- **P:** ภาษาอังกฤษ พูด-ฟัง (พื้นฐาน/ปานกลาง/ดี/ดีมาก/เชี่ยวชาญ)
- **Q:** ภาษาอังกฤษ อ่าน-เขียน (พื้นฐาน/ปานกลาง/ดี/ดีมาก/เชี่ยวชาญ)
- **R:** คะแนนภาษาอังกฤษ (เช่น "TOEIC 650", "IELTS 6.5")

### คอลัมน์ S-T: First Aid
- **S:** ผ่าน First Aid (ผ่าน/ไม่ผ่าน)
- **T:** ทักษะ First Aid (พื้นฐาน/ปานกลาง/ดี/ดีมาก/เชี่ยวชาญ)

### คอลัมน์ U-Y: หลักสูตร/ประสบการณ์ (Array - คั่นด้วย comma)

#### U: หลักสูตรที่ผ่าน
**ตัวเลือก:**
- เคยฝึกประสบการณ์ที่ SAT/ มีประสบการณ์อยู่เวร SAT
- หลักสูตรระบาดวิทยาก่อนปฏิบัติการ
- หลักสูตรการพยากรณ์โรค(ที่จัดโดยกลุ่มพัฒนาองค์กร)
- หลักสูตร FEMT
- หลักสูตร FETH
- หลักสูตร FETP
- หลักสูตร CDCU ระบาดวิทยา
- หลักสูตร CDCU (โรคติดต่ออันตราย)
- หลักสูตร CDCU (ด่าน)
- หลักสูตร ENV-OCC CU
- หลักสูตร VCU
- หลักสูตร IC
- ผ่านการอบรม E-learning ของสถาบันวัคซีนแห่งชาติ
- ผ่านการอบรมจากโรงพยาบาลแม่ข่าย
- ผ่านการอบรมจาก สคร.1
- ผ่านการอบรมจากกองโรคติดต่อทั่วไป
- ผ่านการอบรมสุขาภิบาลสิ่งแวดล้อมเบื้องต้น
- ผ่านการอบรมสุขาภิบาลช่องทางเข้าออกระหว่างประเทศ
- หลักสูตร school based learning สำหรับเจ้าหน้าที่ด่าน
- อื่นๆ

**ตัวอย่าง:**
```
หลักสูตร FETP, หลักสูตร CDCU ระบาดวิทยา, หลักสูตร IC
```

#### V: หลักสูตรโรคติดต่อนำโดยแมลง
**ตัวเลือก:**
- ด้านกีฏวิทยา
- ด้านเครื่องพ่นสารเคมี
- ด้านชันสูตรโรคติดต่อนำโดยแมลง
- อื่นๆ

**ตัวอย่าง:**
```
ด้านกีฏวิทยา, ด้านเครื่องพ่นสารเคมี
```

#### W: หลักสูตร EnvOcc
**ตัวเลือก:**
- หลักสูตร EnvOcc CU (ภาคทฤษฏี)
- หลักสูตร EnvOcc CU (ภาคปฏิบัติ)
- หลักสูตรพนักงานเจ้าหน้าที่ควบคุมโรคจากการประกอบอาชีพ
- หลักสูตรการใช้เครื่องมือตรวจวัดทางสุขศาสตร์อุตสาหกรรม
- หลักสูตรอาชีวอนามัยพื้นฐานออนไลน์
- หลักสูตรอื่นๆเกี่ยวกับอาชีวอนามัย
- จบการศึกษาด้านอาชีวอนามัยและความปลอดภัย
- จบการศึกษาด้านพยาบาลเฉพาะทางด้านอาชีวอนามัย

**ตัวอย่าง:**
```
หลักสูตร EnvOcc CU (ภาคทฤษฏี), หลักสูตรการใช้เครื่องมือตรวจวัด
```

#### X: หลักสูตรกฎหมาย
**ตัวเลือก:**
- หลักสูตร พรบ.โรคติดต่อ 2558
- หลักสูตร พรบ.โรคจากการประกอบอาชีพและโรคจากสิ่งแวดล้อม 2562
- หลักสูตร พรบ. ควบคุมเครื่องดื่มแอลกอฮอล์
- พระราชบัญญัติควบคุมผลิตภัณฑ์ยาสูบ พ.ศ. 2560
- พระราชบัญญัติควบคุมเครื่องดื่มแอลกอฮอล์ (ฉบับที่ 2) พ.ศ. 2568
- อื่นๆ

**ตัวอย่าง:**
```
หลักสูตร พรบ.โรคติดต่อ 2558, หลักสูตร พรบ.โรคจากการประกอบอาชีพ 2562
```

#### Y: ประสบการณ์อื่นๆ
**ตัวเลือก:**
- จัดซื้อจัดจ้างแบบ โดยวิธีเฉพาะเจาะจง
- มีรายชื่ออยู่ในคำสั่งพนักงานขับรถสำรอง ของ สคร.1
- มีรายชื่ออยู่ในคำสั่ง เจ้าหน้าที่พัสดุ ของ สคร.1
- อื่นๆ

**ตัวอย่าง:**
```
จัดซื้อจัดจ้างแบบ โดยวิธีเฉพาะเจาะจง, มีรายชื่ออยู่ในคำสั่งเจ้าหน้าที่พัสดุ
```

## ⚠️ ข้อควรระวัง

### 1. รูปแบบข้อมูล
- ✅ ถูกต้อง: `หลักสูตร A, หลักสูตร B, หลักสูตร C`
- ❌ ผิด: `หลักสูตร A; หลักสูตร B; หลักสูตร C`
- ❌ ผิด: `หลักสูตร A | หลักสูตร B | หลักสูตร C`

### 2. ช่องว่าง
- ถ้าไม่มีข้อมูล ให้เว้นว่างไว้
- ไม่ต้องใส่ "-" หรือ "N/A"

### 3. รหัสพนักงาน
- ต้องเป็นตัวเลข 13 หลัก
- ต้องมีอยู่ในระบบก่อน
- ห้ามซ้ำกันในไฟล์เดียวกัน

### 4. ตัวเลือกหลักสูตร
- ต้องตรงกับตัวเลือกที่กำหนดไว้
- ตัวพิมพ์เล็ก-ใหญ่ไม่สำคัญ
- แนะนำให้ copy จากตัวเลือกที่ระบุไว้

## 💡 Tips

### 1. ใช้ Template
- Export ข้อมูลเดิมออกมาเป็น Template
- แก้ไขข้อมูลใน Template
- Import กลับเข้าไป

### 2. ตรวจสอบข้อมูล
- ตรวจสอบรหัสพนักงานว่ามีในระบบ
- ตรวจสอบรูปแบบข้อมูล Array (คั่นด้วย comma)
- ตรวจสอบค่าทักษะว่าถูกต้อง

### 3. ทดสอบ
- ทดสอบด้วยข้อมูลน้อยๆ ก่อน (5-10 rows)
- ตรวจสอบผลลัพธ์
- แล้วค่อย Import ข้อมูลจริง
